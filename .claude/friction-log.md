- 2026-06-24 · workflow · **Cost a deleted gitignored `.env`.** `cd DIR && cmd > log 2>&1 &` backgrounds the WHOLE pipeline in a SUBSHELL, so the `cd` never moves the MAIN shell. A later same-script `rm -f .env` (intended for DIR) then runs at the ORIGINAL cwd → deleted the repo-root `.env` (gitignored → unrecoverable from git).
